# Switcher Keyboard for MacOS

Лёгкая нативная утилита для macOS (альтернатива Punto Switcher на Swift) для быстрого переключения раскладок и исправления текста, набранного не в той раскладке.

## Возможности

- **Одиночное нажатие `Control`** — переключает раскладку строго по системному порядку (`TISCreateInputSourceList` → `TISSelectInputSource`).
- **Одиночное нажатие `Option`** — переводит выделенный текст или последнее набранное слово (включая слова со знаками препинания вроде `,eltn` → `будет`) из латиницы в кириллицу или обратно, сохраняя раскладку, соответствующую результату:
  - если включена латиница — переводит **только латинские символы** в кириллицу (уже набранная кириллица в смешанном слове остаётся нетронутой);
  - если включена кириллица — переводит **только кириллицу** в латиницу;
  - сохраняет и восстанавливает ваш буфер обмена.
- **Автопереключение раскладки (опционально)** — при нажатии `Space` проверяет набранное слово через встроенный системный словарь `NSSpellChecker` (`en` / `ru`) и автоматически исправляет очевидные опечатки раскладки (игнорирует поля паролей `AXSecureTextField` и горячие клавиши). Можно включить или отключить в меню-баре.
- **Иконка в строке меню (`⇄`)** — статус Универсального доступа, пауза/возобновление, переключатель автопереключения.

## Требования

- macOS 13.0+
- Xcode Command Line Tools (`swiftc`) для сборки из исходников

## Сборка и запуск

```zsh
chmod +x build.sh
./build.sh
open build/MySwitcher.app
```

Скрипт `build.sh` запускает юнит-тесты (`Tests/ConverterTests.swift`), собирает `build/MySwitcher.app` и генерирует иконку `AppIcon.icns`.

### Установка в «Программы» и автозапуск

1. Скопируйте собранное приложение в `/Applications`:
   ```zsh
   cp -R build/MySwitcher.app /Applications/
   ```
2. Откройте `MySwitcher.app` и выдайте разрешение в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
3. Для автозапуска добавьте `MySwitcher.app` в **Системные настройки → Основные → Объекты входа**.

## Структура проекта

- `Sources/Converter.swift` — таблицы соответствия `U.S.` ↔ `RussianWin` и логика частичного/смешанного перевода
- `Sources/AutoSwitcher.swift` — проверка слов через `NSSpellChecker`
- `Sources/InputSourceManager.swift` — работа с раскладками через Carbon `HIToolbox`
- `Sources/TextReplacer.swift` — чтение выделения/токена через `AXUIElement`, замена и восстановление буфера обмена
- `Sources/EventTapManager.swift` — перехват одиночных нажатий `Control`/`Option` и буфер слова через `CGEventTap`
- `Sources/AppDelegate.swift` — меню в строке состояния и настройки
- `Tests/ConverterTests.swift` — юнит-тесты конвертера и автопереключения
- `Resources/AppIcon.png` — исходник иконки приложения
- `build.sh` — скрипт тестирования и сборки `.app`
